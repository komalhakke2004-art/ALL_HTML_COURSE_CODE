WebDevelopmentDescriptionList

HTML
HTML stands for HyperTextMarkupLanguage, HTML depends on <tags> and <tags> are keywords which are used for building the structure of the web page.
CSS
CSS stands for CascadingStyleSheets, CSS depends on rulesets and rulesets are used for styling the HTML/XML elements.
JavaScript
JavaScript is an object-based, object-oriented and scripting language, JavaScript is used for providing the functionality to the HTML/XML elements.
ReactJavaScript
ReactJavaScript is an open-source JavaScript Library, ReactJavaScript is used for designing and developing SinglePage WebApplications.
